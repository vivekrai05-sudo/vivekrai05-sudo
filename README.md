### 🚀 Featured Projects

#### 🤖 [InterviewIQ — AI-Powered Mock Interview Platform](https://github.com/vivekrai05-sudo/Mock_Interview)
*An intelligent AI interview platform automating candidate evaluation with face-tracking and customized RAG engines.*
- **Tech Stack**: React 19, Redux Toolkit, Node.js, Express, MongoDB, Groq AI (Llama-3.3-70b), TensorFlow.js (face-api.js), jsPDF.
- **Key Features**: RAG-based custom question generation from resumes, real-time proctoring (camera checks, face-detection), automated PDF report delivery via Gmail.

#### 🍱 [Vingo — Tiffin Delivery & Management System](https://github.com/vivekrai05-sudo/Tiffin_Delivery)
*A secure MERN food delivery platform supporting Customers, Shop Owners, and Delivery Agents.*
- **Tech Stack**: React, Node.js, Express, MongoDB, Socket.io, Firebase Auth, Geolocation APIs, Razorpay.
- **Key Features**: Role-based routing, real-time order tracking & chats, automated reverse-geocoding, OTP recovery, and Razorpay checkout.

#### 🎓 [MERN Stack Backend course](https://github.com/vivekrai05-sudo/mern_stack)
*A structured, hands-on learning roadmap tracking day-by-day backend development progress.*
- **Key Topics**: Native Mongo driver vs Mongoose validation, Bcrypt password hashing, stateful cookie-stored Refresh Tokens, JWT route authorization, and Redis caching.
